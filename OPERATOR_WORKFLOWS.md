# Operator Workflows

## 1) Start Engagement
1. Open dashboard and select active engagement.
2. Verify status, dates, scope summary, and active work queues.
3. Navigate into target workspace from priority targets.

## 2) Define/Review Scope
1. Open engagement scope records.
2. Confirm in-scope/out-of-scope targets.
3. Use scope checks during command execution; provide override reason when required.

## 3) Import Recon
1. Upload scan artifacts.
2. Normalization maps discoveries into host/service/URL/endpoint structures.
3. Review correlated inventory in target workspace and recon views.

## 4) Work a Target
1. Open target workspace tabs (overview, inventory, web/API surfaces, methodology, credentials, findings, evidence, jobs).
2. Pivot quickly between related records without leaving context.
3. Update test status and notes continuously.

## 5) Capture Burp/HTTP Data
1. Ingest request/response artifacts via integration path.
2. Correlate to target + endpoint where possible.
3. Review in HTTP inspector and create evidence/finding candidates.

## 6) Track Coverage
1. Use methodology profiles and item statuses.
2. Attach evidence/findings to tested items.
3. Monitor coverage and untested work from dashboard/workspace views.

## 7) Capture Evidence
1. Upload evidence with engagement context.
2. Open evidence detail panel for metadata, hash, file info, and associations.
3. Preview inline (image/pdf/text) or download original artifact.
4. Attach/detach to findings and navigate to related records.

## 8) Create/Refine Findings
1. Create finding from workspace context.
2. Add description/impact/repro/remediation and supporting evidence.
3. Move status through review/retest lifecycle.

## 9) Validate Credentials
1. Record credential with type/source/target context.
2. Track validation state and where-used associations.
3. Keep secrets masked until explicit reveal.

## 10) Run Authorized Tool Commands
1. Select template and target.
2. Review command preview.
3. Confirm explicit execution with scope check acknowledgement.
4. Monitor live output and stop if needed.

## 11) Monitor Jobs
1. Use jobs view for running/completed/failed/stopped records.
2. Inspect runtime, command, target, output, and status.
3. Pivot into related target/finding/evidence workflows.

## 12) Retest and Closeout
1. Execute retest queue with original context.
2. Attach new evidence and update finding statuses.
3. Review timeline/activity and generate reporting outputs.
